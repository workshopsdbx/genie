Facilitator guide

Before the day
  1. Heads-up: the registration page says "no setup required", but attendees do need a Free Edition account. Send this page's link with the reminder email and ask them to create a Free Edition account in advance. Sign-in uses an emailed code, Google or Microsoft, and some agency networks block one of these.
  2. Do a full dry run in a fresh Free Edition account: import, Run all, build a space, open the Curated space. Note anything that has moved in the UI.
  3. Have a backup: a pre-built Free Edition workspace you can screen-share if someone's account or network fails.
What the notebooks do

Attendees run one dataset notebook (genie_nyc_aging, genie_nyc_transit, genie_nyc_water or genie_nyc_dohmh). They're generated from the all-in-one genie_byoq_nyc_workshop.py by build_domain_notebooks.py; the all-in-one builds all four datasets for a facilitator demo workspace. Each notebook auto-detects the catalog (current_catalog(), usually workspace) and the SQL warehouse. It builds 4 schemas, 29 tables and 4 metric views, creates a Starter space for each of the four domains, and runs every answer-key query as a self-test. Notebook 2 (genie_byoq_nyc_curated_spaces) creates the four Curated answer-key spaces in about a minute. It's generated from notebook 1's answer key by build_curated_notebook.py, so the two always match. Notebook 1 widgets: genie_spaces (starter / both / curated / none), metadata_level (basic / rich), share_with_group (paid workspaces only). Re-running is safe: same seeds, same numbers, and spaces are updated in place by title.

Demo: "metadata alone" (optional, 10 min)

On your own workspace after Round 1, re-run with metadata_level = rich and genie_spaces = none. This rewrites the UC comments with usage rules (e.g. "never SUM arrears across months"). Re-ask the traps in an uncurated space: most now pass with no Genie instructions at all.

Running on a paid workspace instead

The same notebook works on any Unity Catalog workspace. Set catalog and warehouse_id, and optionally share_with_group to grant attendees USE / SELECT / CREATE TABLE on the schemas and CAN RUN on the spaces.

Timing tips (matches the registration agenda)

Get every laptop through setup during arrivals (8:30–9:00), and have people write their 2–3 questions in Your questions while their notebook runs. That list is what makes it a BYOQ workshop: Round 1 and Round 2 each come back to it. The notebook needs 5–10 minutes, and the 10:00 break is the last safe moment to start it. The 60-minute hands-on lab covers Labs 1–2, Round 1, and the core of Round 2 (instructions + trusted asset). If a table falls behind, skip Lab 2 and go straight from building the space to Round 1. The open lab (11:30–12:15) is self-paced: deeper curation, metric views, benchmarks or BYOQ. Lab 7 is the 12:15 wrap-up talk track.
